# PROJECT_NAME

A minimal Bun-first TanStack Start app with Ultracite, Bun tests, and React Doctor.

```bash
bun install
bun run dev
```

Edit `src/routes/index.tsx` to get started. Add route files under `src/routes`;
TanStack Router updates `src/routeTree.gen.ts` for you.

Useful checks:

```bash
bun run check
bun run test
bun run doctor
bun run build
```
